# Ảnh trang chủ

Các ảnh WebP dùng trong `HomeSlideshow` được lấy từ bộ thiết kế người dùng cung cấp,
giữ nguyên nội dung và tối ưu dung lượng. Đây là ảnh minh họa, không phải tin phòng thực tế.

- `home-balcony.webp`: `design-reference/.../cozy_aesthetic_studio_apartment_room_in_danang_with_a_balcony_sheer_white/screen.png`.
- `home-sunlight.webp`: `design-reference/.../bright_airy_modern_clean_rental_bedroom_in_danang_vietnam_with_large_window/screen.png`.
- `home-evening.webp`: ảnh phòng với cửa sổ thành phố buổi tối trong `design-reference/.../kh_m_ph_ph_ng/code.html`.
- `home-loft.webp`: ảnh căn phòng gác lửng trong cùng file HTML.

Hai ảnh sau được tải từ đúng URL ảnh có sẵn trong HTML và lưu local để website
không phụ thuộc URL bên ngoài khi hiển thị. Thư mục `design-reference` gốc vẫn được Git bỏ qua.
